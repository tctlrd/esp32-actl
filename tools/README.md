# Tools

## latest npm dependancies
Optional: `npm install -g npm-check-updates` to install the update checker tool and run the `ncu -u` commmand in the 'webfilesbuilder' folder to update the dependancies to their latest versions in the 'package.json' file.

## run the web files builder
The webfiles are located in src/websrc/ and will be built and compressed into src/webh when the web files builder is run.

1. run `npm install` to install the builder
2. run `npm start` to run the web files builder
